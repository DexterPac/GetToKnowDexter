Task Goblin is my Student Innovation Project (SIP) at UAT. This project gave me the opportunity to identify the need for a digital distraction mitigation tool. Subsequently, I would refine the project's scope to determine the project should include basic task creation and editing in addition to distraction detection logic tailored for browser useage. Weekly stand-ups/updates and testing amongst peers were also conducted to help improve user experience, especially user navigation of the extension.
More information can be viewed about this specific project from the SIP subpage or visit the project's GitHub.
NEWS was a project meant to help users discover events around the globe that might otherwise be ignored from major outlets. This project would also demonstrate planning architectural layout of the project, by following a Model-View-Controller structure. The project was designed as a mobile application, but acceptable functionality for web access if a mobile device or emulator was not available. This project would need to be usable across different mobile device models, so testing with emulators would prove beneficial to improve and standardize user experience.
