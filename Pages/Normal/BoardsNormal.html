OBJECTIVE 5

Design, develop, and maintain object-oriented software solutions utilizing inheritance, encapsulation, polymorphism, and abstraction.

This project is a simulation that demonstrates object oriented programming techniques like encapsulation and abstraction. The program groups key functions and variables related to the player character and organizes them based on if they should be externally or internally accessed from outside or within the grouping. The program also establishes these function in a way that the user does not need to understand their internal workings to utilize them. For example, a load data function does not require the user to utilize numerous other functions to achieve a similar effect, but rather simply pass their existing player character and let the function handle the rest.
This project is another simulation that demonstrates simple object oriented programming techniques like inheritance and polymorphism. The program has children "Ninja" and "Pirate" classes inherit functions from their parent "Character" class; so a Ninja or Pirate instance can utilize said functions without having to go through their parent class. Furthermore, these classes have overridden certain inhherited functions to adapt them to their specific needs.

OBJECTIVE 6

Within software solutions, describe, implement, and analyze data structure techniques.

This project is a program that helps determines where you should go out to eat based on previous preferences. It utilzes a hashmap that stores food genres as keys that access an array of corresponding food values. The program also uses a hashset to store and access the aforementioned keys. Arraylists are implemented to dynamically add or remove food options.
This project is meant to demonstrate the implementation of a binary search tree that accepts generic parameters. The program allows the user to add an input to the tree, which then creates and sorts the inputs into hierarchical and branching nodes. Recursion is utilized to traverse and modify the tree - used in its insert, search, and delete functions.
