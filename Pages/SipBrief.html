Task Goblin

Technical Field

This project involves the technical fields of web application development and browser extension development, with emphasis on front-end programming and user-focused interface design. The intended major behind this field is focused around Computer Science.

Background Information

In an increasingly fast-paced, digitally driven environment, maintaining focus on a primary task has become more difficult due to constant online distractions. Productivity tools often attempt to eliminate distractions entirely, which is an unrealistic expectation for most users. The inspiration for this project comes from the need for a balanced solution that not only discourages distractions but also actively redirects users back to their goals when distractions occur. By integrating motivation, time awareness, and optional enforcement directly into the browser, this project addresses a growing demand for adaptable productivity tools that align with real-world user behavior rather than rigid control.

Prior Art (Research)

Motivate is a Chrome extension that displays a constant visual reminder of a user’s goal and target date across browser tabs to encourage focus. While effective as a passive reminder, it does not actively intervene when distractions occur. Task Goblin differs by incorporating interactive pop-ups, progress check-ins, and optional anti-distraction mechanisms with adjustable severity levels, providing a more adaptive and responsive approach to focus management. StayFocusd is a productivity extension that restricts or blocks access to time-wasting websites once predefined usage limits are reached. Although effective for strict enforcement, it lacks motivational and goal-oriented components. Task Goblin combines website warnings and optional blocking with goal tracking and motivational feedback, allowing users to choose between guidance and restriction within a single unified system.

Project Description

This project proposes the development of a browser-based task reminder and anti-distraction extension designed to help users remain focused during online activities. The extension supports task creation, time tracking, progress check-ins, and customizable interventions when distractions occur. Intended for students, remote workers, and professionals, the application integrates motivational reminders and optional restriction tools directly into the browser to reduce cognitive load and eliminate the need for multiple productivity applications.

Innovation Claim

This project is innovative because it combines goal tracking, motivational feedback, and customizable anti-distraction enforcement into a single browser extension that adapts to varying user needs rather than enforcing a one-size-fits-all productivity solution.

Usage Scenario

Beyond individual productivity, this innovation could be used in structured learning or training environments where maintaining focus is critical, such as online coursework platforms or remote onboarding programs. In these contexts, the system could guide users back to assigned materials, reinforce time-bound objectives, and discourage unrelated browsing without fully restricting access. The value provided lies in its adaptability, supporting accountability and self-regulation while preserving user autonomy.


Evaluation Criteria

“The following questions will identify the successful completion of the project.”

  • Does the extension allow users to create and manage tasks with time limits?
  • Do motivational reminders appear at appropriate intervals?
  • Can users define distraction websites for warnings or restrictions?
  • Does the extension support multiple intervention intensity levels?
  • Is the user interface intuitive and easy to navigate?
  • Do anti-distraction features activate correctly when conditions are met?
  • Can users modify or disable features without breaking functionality?
  • Does the extension operate without noticeable performance issues?

Goals & Tasks Associated With Project

Objective 1: Core Extension Functionality
Task 1.1 – Browser Extension Setup (Target: Early Development Phase)
Set up the Chrome extension framework, including manifest configuration and basic file structure. Decisions will be guided by Chrome extension policy requirements and scalability considerations.

Task 1.2 – Task and Time Management System
Implement task creation, editing, and time tracking features using JavaScript and browser storage APIs. Design decisions will prioritize clarity and minimal user input.

Objective 2: Anti-Distraction Features
Objective 2: Anti-Distraction Features
Develop logic to detect user visits to predefined distraction websites and trigger warnings or interventions accordingly.

Task 2.2 – Intensity Level Controls
Implement multiple intervention levels, allowing users to adjust how aggressively the extension responds to distractions.

Objective 3: User Interface and Experience
Task 3.1 – Interface Design
Design a clean and minimal user interface using HTML and CSS to ensure ease of navigation and low cognitive load.

Task 3.2 – User Feedback and Testing
Conduct informal usability testing to refine interface flow and feature clarity based on observed behavior.

Description of Prototype

The design prototype will be implemented as a Chrome browser extension developed using HTML, CSS, and JavaScript. The prototype will include a basic task setup interface, a settings panel for intervention intensity, and functional pop-up reminders. Users will install the extension locally in developer mode and interact with it through the browser toolbar. The prototype will demonstrate the core functionality of task reminders, distraction detection, and adjustable intervention behavior, serving as a foundation for the final project.
